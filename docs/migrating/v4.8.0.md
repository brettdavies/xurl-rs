# Migrating to xr 4.8.0: a minor under the small-break exception

`xr` 4.8.0 names the signal that ended a stream. A stream that Ctrl+C (SIGINT) ends writes `reason: "sigint"` in its
`cancelled` document, where 4.7 wrote `sigterm` for every signal. A script written against 4.7 that matches
`sigterm` to catch Ctrl+C stops matching it. The change ships in a minor release under the small-break exception
(`RELEASES.md` § "The bump"): the break is one value of one field, and SIGTERM, the exit code, and the shape of the
document are unchanged.

## Streams

| 4.7                                                            | 4.8                   | Notes                                               |
| -------------------------------------------------------------- | --------------------- | --------------------------------------------------- |
| Ctrl+C (SIGINT) ends a stream: `"reason": "sigterm"`           | `"reason": "sigint"`  | a script that matched `sigterm` for it matches both |
| SIGTERM ends a stream: `"reason": "sigterm"`                   | `"reason": "sigterm"` | unchanged                                           |
| Ctrl+C on Windows, which has no SIGTERM: `"reason": "sigterm"` | `"reason": "sigint"`  | `sigint` is the only value a Windows stream writes  |

A stream is a raw request sent with `-s`, or one to a streaming endpoint such as `/2/tweets/search/stream`. Under a
structured `--output` format (anything but `text`), a signal ends it with one `cancelled` document on stdout after the
records it already printed, and the run exits 0. Under `--output jsonl` the document reads:

```json
{"status":"cancelled","reason":"sigint"}
```

Under `--output text` no document is written. The document has no other key, so `reason` is the only field that moves.

A filter that picks out the document by its reason matches both values in 4.8:

| 4.7                                  | 4.8                                                         |
| ------------------------------------ | ----------------------------------------------------------- |
| `jaq 'select(.reason == "sigterm")'` | `jaq 'select(.reason == "sigint" or .reason == "sigterm")'` |

A script that tests `.status == "cancelled"` alone needs no change. `reason` stays a plain string, not one of the error
`reason` codes, and `schema/output.schema.json` describes the `cancelled` document with both values.
